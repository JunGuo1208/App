# 随类换色台

丙烯马克笔画画助手（单页网页 App，`index.html`）。

- **换色**：别人的画 / 自己的照片 → 提取主色 → 对应到「我的笔」里最接近的色号；可看「换成我的笔」预览和带色号的「画稿」（数字油画式线稿）；点图取色；Claude 排临摹步骤。
- **想画**：收藏参考图（可粘贴小红书分享文字自动填标题、作者、链接），按标签 / 色号搜索，标记「下一张」，筛选「笔都在的」。
- **画过**：记录完成的作品（照片、日期、用时、自评、心得），统计最常用的笔。
- **我的笔**：拍色卡导入（框四角自动取色，可让 Claude 认色号）、文字导入导出、标记快没水 / 没了、补货清单。
